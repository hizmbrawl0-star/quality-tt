# TikTok Quality

Прототип для TikTok 47.8.0 (478036), arm64. Твик обрабатывает выбранный MP4 на iPhone, пишет прогресс по фактически записанным байтам и передаёт временную копию обработчику TikTok. События отображаются в окне подготовки и в системном журнале с меткой `[TikTokQuality]`.

Обработка воспроизводит результат CompressBase Quality + FPS для предоставленного примера. Видеоданные и их тайминг сохраняются. Поддерживается обычный MP4 со стерео AAC-LC 48 кГц и структурой метаданных, которую умеет обработать прототип. Для несовместимого видео окно показывает ошибку и предлагает продолжить с оригиналом.

## Сборка и установка

1. Распакуй архив и добавь содержимое папки `TikTokQuality` в корень своего репозитория. Включи папку `.github`.
2. Сборка запускается при отправке исходников и workflow в репозиторий. Для ручного запуска открой **Actions → Build TikTok Quality tweak → Run workflow**.
3. В результате сборки скачай артефакт **TikTokQuality** и достань из него `TikTokQuality.dylib`.
4. В Feather добавь `TikTokQuality.dylib` как твик к своему IPA TikTok 47.8.0, подпиши и установи.
5. Выбери исходный MP4 через «Загрузить». Проверь, появилось ли окно подготовки и открылся ли экран с описанием. Для проверки качества опубликуй ролик в режиме «Только я» и замерь разрешение и FPS при воспроизведении.

Сборке в GitHub Actions нужны только исходники. IPA и сертификат используются в Feather.

## Статус проверки

Workflow прошёл проверку actionlint. На Windows модуль подготовки MP4 собран Clang с предупреждениями как ошибками. SHA-256 результата совпал с SHA-256 файла CompressBase для предоставленной пары. Синтаксис Objective-C++ и ARC проверен Clang с локальными объявлениями интерфейсов. Сборка с настоящим iOS SDK и вызов обработчика выбора видео на iPhone ещё не проверены.
